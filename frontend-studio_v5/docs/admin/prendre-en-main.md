
Vous venez de bénéficier de l'installation d'une instance Aktivisda et vous souhaitez la prendre en main, ce guide synthétise les différentes étapes pour prendre en main votre instance.

## Qu'est-ce qui a été fait ?

Pour vous permettre de pouvoir utiliser votre instance, plusieurs choses ont été faites :

* **hébergement de votre instance** sur un serveur web. Vous pouvez essayer de vous connecter à l'url qui vous a été fournie (potentiellement avec des identifiants) ;
* mise en place d'un **Matomo** pour suivre le nombre de connexions à votre instance (en respectant la vie privée). Vous devez avoir un lien pour créer votre compte et accéder à vos données ;
* création d'un projet privé sur [Framagit](https://framagit.org/) avec toutes les données de votre instance. Pour y accéder, vous devez (1) créer un compte puis une fois le compte validé (délai de 1 à 5j) (2) communiquer votre pseudo Framagit ;
* création d'un compte pour accéder au **serveur communautaire** de traitement d'images (compressions, vectorisation), les identifiants vous ont été transmis ;
* ajout d'un **monitoring** de votre instance afin de déceler d'éventuelles interruptions de services ;
* mise en place de la **configuration** de base, notamment :
 * ajout des **polices de caractères** ;
 * ajout des **couleurs** ;

Tous ces éléments ont été configurés de manière à ce que toute mise à jour de votre projet Gitlab soit répercutée automatiquement sur votre instance Aktivisda.

## Votre rôle

En tant qu'administrateur·ice de votre instance, votre rôle est principalement d'ajouter du nouveau contenu sur votre instance, en particulier les images et gabarits. Pour cela vous avez accès à une interface d'administration, backtivisda.

Cet outil est documenté sur cette documentation, voir [backtivisda](/admin/backtivisda/).
