Ci-dessous une liste avec les différents éléments à ressembler et questions à se poser avant d'envisager la création d'une instance Aktivisda.

## Questionner le besoin

Aktivisda est un outil web pensé pour la **création graphique** des **organisations décentralisées**. Ce n'est par exemple pas un clone de Canva.

- [ ] Bien lire [ce qu'est Aktivisda](https://aktivisda.earth) et identifier si son organisation pourrait être intéressée ;
- [ ] Parcourir les [différentes instances](/showcase) connues de Aktivisda et se faire une idée des fonctionnalités ([descriptif fonctionnel complet](/features)) ;
- [ ] Impliquer les graphistes de l'organisation dans le projet et s'assurer qu’iels souhaitent que ce projet se réalise ;
- [ ] Impliquer la _direction_ de l'organisation et valider avec elles et eux que c'est ok que n'importe qui puisse créer des visuels sans contrôle central ;

## Rassembler les éléments pour initier votre instance

Une instance sans contenu, ça n'a pas d’intérêt. Voici les éléments principaux dont vous avez besoin pour créer votre instance :


**Personnaliser votre l'instance**

- [ ] Choisir le nom de l'instance et son url ;
- [ ] Choisir des couleurs primaire et secondaire de l'instance ;

**Rassembler votre charte graphique** :

- [ ] Polices de caractère (au moins une) : le nom et un fichier (`.ttf`, `.otf` ou `.woff`) ;
- [ ] Lister les couleurs utilisées (codes html);
- [ ] Rassembler votre logo (et ses variations) au format vectoriel ou au moins en très haute résolution ;
- [ ] Rassembler quelques images ou photos utilisées sur les visuels ;
- [ ] Créer deux ou trois exemples de visuels qui pourraient être créés avec Aktivisda ;
- [ ] Rassembler un ou plusieurs exemples d'images de fonds (photos ou format vectoriel) ;
