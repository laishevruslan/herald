# Tests

Aktivisda dispose de tests d'intégration [Cypress](https://www.cypress.io/) actuellement non exécutés dans la CI.

## Commencer

-   Démarrer cypress
    ```terminal
    npm run cypress:open
    ```

-   Démarrer Aktivisda au port `8080`
    ```terminal
    npm run serve:aktivisda
    ```

## Développer

Les tests sont définis dans le dossier `cypress`
