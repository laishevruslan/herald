title: 1️⃣ Edit visual content easily
---

Aktivisda lets you create powerful visuals using editable templates. Move, resize, duplicate, reorder elements — all directly in your browser. Vector graphics (SVG and SVGZ) are supported, allowing scalable, lightweight, color-adaptable assets.

Add and style text, background images, shapes, and even photos. Most actions can be done via keyboard shortcuts: `Ctrl+D` to duplicate, `Ctrl+Z` to undo, `PageUp/PageDown` to reorder layers, and more.

You can export your work as **PNG**, **JPG** or **PDF**, with real vector support for high-quality prints. You can also save and reload your visual as a JSON file — or even generate a sharable URL (if not too complex).
